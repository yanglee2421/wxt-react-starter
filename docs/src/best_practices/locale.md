# 国际化路由

## 路由结构

```yaml
root_route:
  - route_index
  - lang_route
    - not-found_route
    - other_routes
```

### 根路由

负责包裹所有路由，当需要对所有路由页面进行一些统一操作时会很有用，比如为你的路由器增加一个[nprogress](https://www.npmjs.com/package/nprogress)进度条。

### 首页路由

首页路由代表`path`为`/`的页面。当用户进入首页路由时，触发重定向到类似`/en`的路径，这个重定向发生在服务器中时（比如[Next.js](https://nextjs.org/)）首页路由不显示任何内容，当发生在单页面应用（比如[react-router](https://reactrouter.com)库模式或[vue-router](https://router.vuejs.org/)）中时，可以显示一个全局的加载画面。

在重定向逻辑中，先计算出目标语言，即用户上一次选择的语言，若找不到上次访问时用的语言，则返回默认

### 多语言路由

多语言路由代表`path`为`/en`和`/en/xxx`的父路由，在路由器配置中它需要被配置为类似`:lang`的动态路由。

重定向的计算逻辑如下:

1. 当用户传入的是一个非多语言路径比如`/login`、`/signup`和`/dashboard`，为它们添加多语言前缀。
2. 当用户传入的是一个带多语言前缀的路径比如`/zh/login`、`/fr/signup`和`/en/dashboard`

- 若匹配当前设置则放行
- 若不匹配当前语言且指定不需要返回新路径，则修改配置的当前语言为路径中的语言
- 若不匹配当前语言且指定需要返回新路径，则修改路径中的语言为当前语言

### 多语言404路由

需要这个路由来正常处理404路径会正确触发多语言重定向，换言之，若不配置这个路由则没有匹配的路由不会触发多语言重定向
